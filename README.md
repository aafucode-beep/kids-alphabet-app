# ABC Animals!

A fun, interactive HTML app for 4-year-old children to learn the 26 English letters.

## Features

- **Learn Mode** - Tap any letter card to see the letter, animal, and hear pronunciation
- **Listen Mode** - Auto-plays through the alphabet with voice narration
- **Play Mode** - Interactive matching game: match animals to their starting letters

## How to Use

1. Download index.html
2. Open it in any modern web browser
3. Turn on your volume for voice narration
4. Enjoy learning!

## Tech

- Pure HTML/CSS/JavaScript (single file, no dependencies)
- Web Speech API for voice narration
- Responsive design for tablets and phones
